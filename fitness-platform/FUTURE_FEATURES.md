# Optional ideas beyond the defined product scope

This file deliberately does **not** contain any feature already required by the master product specification. Those belong in `IMPLEMENTATION_PLAN.md` and remain planned mandatory scope.

Possible post-roadmap explorations:

- Privacy-preserving federated aggregate research for population trends, only after formal review.
- Dedicated large-screen gym/kiosk companion that never exposes private health fields.
- Open, versioned export/import package usable by independent tools beyond basic GDPR export.
- Plugin SDK for institution-owned, signed exercise content packs with strict capability sandboxing.
- Research-only motion/form analysis performed entirely on-device with uncertainty display and no injury diagnosis.

None is approved, scheduled or represented as implemented.
